# CI/CD 流程（GitHub Pages 部署）

## 整体流程

```
git push main → GitHub Actions 自动触发
  → checkout 拉代码 → 装 pnpm → pnpm install
  → pnpm build 构建 → 上传 dist 产物 → 部署到 GitHub Pages
  → 访问 https://enemyyourforever.github.io/CICD/
```

## 关键配置点

| 配置                                       | 位置                         | 作用                               |
| ------------------------------------------ | ---------------------------- | ---------------------------------- |
| `base: '/CICD/'`                           | vite.config.ts               | 资源路径适配子路径，不加会白屏     |
| `createWebHistory('/CICD/')`               | src/router/index.ts          | 路由 History 模式适配子路径        |
| workflow 文件                              | .github/workflows/deploy.yml | 触发 + 构建 + 部署的完整流水线     |
| Settings → Pages → Source = GitHub Actions | GitHub 网页                  | 允许 workflow 部署（漏了部署不上） |
| `--frozen-lockfile`                        | deploy.yml                   | 严格按 lock 文件装依赖，版本不漂移 |

## workflow 触发时机

- `push` 到 `main` 分支自动跑
- `workflow_dispatch` 可网页手动触发
- `concurrency` 同分支新推送取消旧运行

# 关键配置写法

## vite.config.ts 三个要点

```ts
export default defineConfig({
  base: '/CICD/', // GitHub Pages 子路径
  plugins: [vue()],
  build: {
    minify: 'terser', // 用 terser 压缩
    terserOptions: { compress: { drop_console: true } }, // 删 console
    rollupOptions: {
      // vue 单独分包，利于缓存
      output: {
        manualChunks(id) {
          if (id.includes('node_modules/vue')) return 'vue';
        },
      },
    },
  },
});
```

## eslint.config.js 结构（flat config）

```
① ...pluginVue.configs['flat/recommended']   Vue 规则（数组整体展开，不能取 .rules）
② 自定义段：TS 规则 + no-console: warn + html-self-closing
③ eslintConfigPrettier                     必须放最后（关格式冲突）
④ ignores: dist/node_modules
```

## .husky/pre-commit

```
pnpm exec lint-staged
```

## deploy.yml 骨架

```yaml
on: { push: { branches: [main] }, workflow_dispatch: }
permissions: { contents: read, pages: write, id-token: write }
jobs:
  build:  checkout → pnpm/action-setup → setup-node(cache: pnpm)
          → pnpm install --frozen-lockfile → pnpm build
          → configure-pages → upload-pages-artifact(path: dist)
  deploy: needs: build → deploy-pages
```

# 踩过的坑

| 坑                           | 原因                                 | 解决                                   |
| ---------------------------- | ------------------------------------ | -------------------------------------- |
| 白屏                         | 路由 History 模式没配 base           | `createWebHistory('/CICD/')`           |
| CI 报 packages field missing | pnpm-workspace.yaml 无 packages 字段 | 加 `packages: []`                      |
| esbuild.drop 类型报错        | Vite 8 已弃用 esbuild 改用 Rolldown  | 用 `minify: 'terser'` + `drop_console` |
| git push origin 失败         | 远程名是 CICD 不是 origin            | 用 `git push CICD`                     |
| 删远程分支被拒               | 不能删 GitHub 默认分支               | Settings 改默认分支为 main 后再删      |
